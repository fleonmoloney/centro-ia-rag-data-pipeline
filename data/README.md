# Datos de ejemplo

`synthetic_corpus/` es un corpus **ficticio** escrito para probar el pipeline. Las instituciones
("Hospital Modelo", "Ministerio Modelo", "Instituto Modelo"), los plazos, los montos y los
procedimientos son inventados y no representan ninguna norma ni protocolo real.

Sirve para verificar que la recuperación, los filtros y las abstenciones funcionan. No permite
concluir nada sobre el rendimiento con documentos reales: para eso hay que evaluar con tu corpus.
